# 🗣️ voicespeak

Превращает русский текст в живую озвучку — локально, одной командой.
На вход даёшь текстовый файл, на выходе получаешь аудио. Никакого облака, ключей и подписок.

Единственное, что нужно на машине — **Docker** и **bash**. Всё остальное (нейросеть, вокодер,
простановка ударений, модели) уже упаковано внутрь образа.

---

## Быстрый старт

```bash
git clone git@github.com:withoutforget/voicespeak.git
cd voicespeak

./run.sh example.txt            # первый запуск сам соберёт образ, затем -> output.wav
```

Готово — рядом появится `output.wav`. Всё.

Свой текст и своё имя файла:

```bash
./run.sh моя_история.txt озвучка.wav
```

---

## Что под капотом

Голос собран как максимально «человечный» вариант, который реально работает на домашнем железе:

- **F5-TTS** (русский accent-tune) — синтезирует речь.
- **RUAccent** — сам расставляет ударения, поэтому получается «тИхим», а не «тихИм».
- **Студийный референс** (`assets/studio_ref.wav`) — задаёт тембр и манеру голоса.
- **ffmpeg loudnorm** — выравнивает громкость, чтобы не было тихо.

Почему именно так: дообучение собственной модели на слабой видеокарте оказалось *хуже*, чем
аккуратный zero-shot по чистому студийному референсу. Поэтому в основе — он.

## Как пользоваться

| Команда | Что делает |
|---|---|
| `./run.sh example.txt` | Озвучить файл → `output.wav` |
| `./run.sh in.txt out.wav` | Свой путь для результата |
| `./run.sh in.txt out.wav --nfe 16` | Быстрее (≈вдвое), качество чуть проще |
| `./run.sh in.txt out.wav --speed 1.1` | Ускорить/замедлить темп речи |
| `./run.sh bench` | Замерить скорость инференса на этой машине |
| `./run.sh build` | Пересобрать образ вручную |

### Бенчмарк

```bash
./run.sh bench            # RTF при nfe=32 и nfe=16 на твоём железе
./run.sh bench --runs 3   # больше повторов (берётся лучший)
```

Гоняет фиксированный текст (детерминированно) и печатает железо, RTF, «во сколько раз
быстрее реального времени» и пик VRAM — удобно сравнивать разные машины. В конце — короткая
строка `ИТОГ: [GPU] nfe32=RTF… ` для обмена результатами.

Во время работы видно прогресс: `[voicespeak] …` и в конце — сколько секунд аудио за сколько
секунд посчиталось.

---

## GPU или CPU — само разберётся

- Есть NVIDIA GPU и `nvidia-container-toolkit` → `run.sh` сам добавит ускорение (`--gpus all`).
- Нет → всё честно посчитается на CPU (медленнее, минуты на фразу — но работает везде).
- Точность намеренно FP32: корректно на любой карте, включая капризную к FP16 GTX 1660.

Примерная скорость (RTF = время счёта / длительность аудио, меньше — лучше):

| Железо | RTF | По-человечески |
|---|---|---|
| GTX 1660 | ~3.2 | медленнее реального времени |
| RTX 3060 / 4060 | ~0.3–0.5 | быстрее реального времени |
| Только CPU | ~10–30 | минуты на фразу |

## Сменить голос

Хочешь другой тембр — положи свой **чистый** референс (5–12 секунд, один голос, без шума и музыки)
в `assets/studio_ref.wav`, впиши его текст в `assets/studio_ref.txt` и пересобери:

```bash
./run.sh build
```

## Что где лежит

```
voicespeak/
├── run.sh          ← единственная точка входа
├── Dockerfile      ← самодостаточный образ (модели вшиты, старт офлайн)
├── speak.py        ← генерация внутри контейнера
├── assets/         ← референс голоса + его расшифровка
└── example.txt     ← пример текста
```

## Лицензия и модели

Код — делай что хочешь. Модели тянутся из открытых репозиториев (F5-TTS RU, RUAccent, Vocos)
и вшиваются в образ на этапе сборки; их лицензии — на стороне авторов.
